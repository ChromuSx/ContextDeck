# ContextDeck support

## Getting help

Use [GitHub Issues](https://github.com/ChromuSx/ContextDeck/issues) for
reproducible bugs and feature requests.

Include:

- ContextDeck version;
- Stream Deck software version;
- Windows version;
- Stream Deck device model;
- foreground application;
- expected and actual selection category;
- relevant privacy-reviewed log lines.

Never post selected text, private filenames, full paths, device serial numbers,
credentials, or other personal data.

## Common checks

- Confirm Stream Deck 6.9 or newer is installed.
- Confirm the profile installation prompt was accepted.
- Test text detection in Notepad.
- Test file and folder detection in Windows File Explorer.
- Verify the foreground application is not excluded in ContextDeck settings.

Security vulnerabilities should not be reported in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
