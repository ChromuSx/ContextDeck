# Security policy

## Supported versions

Security fixes are applied to the latest published ContextDeck version.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/ChromuSx/ContextDeck/security/advisories/new).

Include:

- affected version;
- reproduction steps;
- impact;
- suggested mitigation, if known.

Do not open a public issue until the report has been reviewed.

## Privacy boundary

ContextDeck is designed not to serialize selected text, file paths, filenames,
or file contents. A report that demonstrates content crossing this boundary is
considered security-sensitive.
